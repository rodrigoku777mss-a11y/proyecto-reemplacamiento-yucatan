# Sistema de Reemplacamiento Vehicular - Yucatán

Proyecto final de gestión vehicular desarrollado en Java con arquitectura DAO, base de datos en MySQL 8.0 desplegada en contenedor Docker y normalización en Tercera Forma Normal (3FN).

## Requisitos Previos
* Docker y Docker Desktop
* Java JDK 17 o superior
* MySQL Connector/J
